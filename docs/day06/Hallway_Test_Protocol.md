# Day 6 five-person hallway test

## Decision rule

Promote the flagged information architecture beyond the internal cohort only if at least **four of five** eligible participants correctly choose:

1. **My Classes** for recurring work where level, goal, and teaching history should carry forward.
2. **Quick Create** for one-off work that does not need continuing class context.

A participant counts as correct only when both choices are correct without coaching. Record no names, Telegram IDs, school names, student information, or free-form personal details.

## Procedure

1. Show the flagged home screen without explaining the button labels.
2. Give the two scenarios below. Counterbalance order: P01, P03, and P05 receive Scenario A first; P02 and P04 receive Scenario B first.
3. Ask, “What would you tap first, and why?” Do not confirm or correct the first answer until both scenarios are complete.
4. Record only the selected button and a short de-identified reason code.
5. Mark the participant correct only if both expected choices were made independently.

### Scenario A — recurring

“You teach the same group every week. You want the next activity to use that group’s level, goal, and earlier teaching history. What would you tap first?”

Expected: **My Classes**.

### Scenario B — one-off

“You need one worksheet for a substitute lesson and do not need TeacherOS to remember a class afterward. What would you tap first?”

Expected: **Quick Create**.
