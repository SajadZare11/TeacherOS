# Day 7 observed setup timing test

## Gate

Observe three real teachers completing class setup without coaching. The median completion time must be **under 120 seconds**, and no required typed answer may exceed one short phrase.

Do not record names, Telegram IDs, schools, student details, class labels, coursebook text, health/disability information, or screen recordings containing private content.

## Procedure

1. Start from the flagged My Classes empty state.
2. Say: “Create a class that would be useful for your recurring teaching. Think aloud, but I will not guide you.”
3. Start the timer when Create a Class is tapped.
4. Stop when the completed class screen appears.
5. Record seconds, whether help was requested, the longest required typed answer’s word count, and only a controlled friction code.
6. If the teacher stops, record the abandonment field from the product event and do not copy their entered content.

Allowed friction codes: `none`, `label_unclear`, `too_many_steps`, `choice_missing`, `navigation_confusion`, `privacy_concern`, `other_deidentified`.
