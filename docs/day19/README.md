# Day 19 — Meaningful Differentiation and One-Tap Classroom Adaptations

Day 19 of TeacherOS finishes **Phase 3 Core Adaptations** by delivering 3-tier scaffolding and 9 emergency one-tap classroom adaptations.

---

## 1. 3-Tier Differentiation Model

| Tier | Pedagogical Access Strategy | Invariant Guard |
| :--- | :--- | :--- |
| **🟢 Support Route** | Step-by-step guidance, target word banks, sentence frames, and paired coaching. | **Never lowers the standard or alters the objective.** |
| **🟡 Core Route** | Expected grade/level performance with standard independent execution. | Balanced baseline for whole-class synthesis. |
| **🟣 Challenge Route** | Open-ended synthesis, nuanced critique, counter-argumentation, and real-world transfer. | **Adds cognitive depth, NOT extra volume/busywork.** |

### Delivery & Reconnection Guidance
- **Discreet Distribution:** Color-coded task slips (Green / Gold / Purple) or self-selection choice boards prevent student stigmatization.
- **Active Monitoring:** 4-minute targeted observation for Support groups followed by roaming Challenge check-ins.
- **Whole-Class Reconnection:** Structured 5-minute debrief where findings from all 3 tiers combine into the shared class can-do objective.

---

## 2. 9 Standard One-Tap Classroom Adaptations

1. **⏱ Shorter Version (-15 to 20 mins):** Merges warm-up stages into rapid 5-minute hook and focuses on core output.
2. **⏳ Extended Depth (+15 mins):** Adds structured peer debate and metacognitive defense.
3. **🚀 Fast Finisher Extension:** Lateral thinking tasks, rule-explainer cheat sheets, and peer editor roles.
4. **🛟 High-Scaffold Route:** Graphic organizers, bilingual vocabulary hints, and visual starters.
5. **🧠 Challenge Extension:** Strict concessive clause requirements and alternative counter-claims.
6. **📝 Zero-Tech / Low-Resource:** Paper/chalkboard layout runnable without audio, projector, or internet.
7. **👥 Large Class Protocol (25+):** Pyramid pairing (1 $\rightarrow$ 2 $\rightarrow$ 4) and silent hand signaling.
8. **🗣 More Communicative:** Paired oral information-gap and negotiated compromise tasks.
9. **📊 Exam Task Format:** Timed simulation with official band descriptors and marking criteria.
